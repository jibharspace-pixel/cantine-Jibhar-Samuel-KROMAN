## Présentation

le projet est un programme JavaScript qui calcule le montant d'une commande de cantine à partir de certains paramètres ( client,  plat choisi,  quantité totale de portions commandées, montant versé ) .
 Il affiche dans le terminal un récapitulatif : une ligne par portion, le total à payer, la monnaie à rendre ou le montant manquant à payer

## Commande d'exécution

node .\cantine.js est un programme qui peut se lire en deux points :

le programme node qui execute et le fichier à executer  et le
" .\cantine.js" répresente le chemin du fichier 

une fois cette commande exécutée node lit notre fichier de haut en bas et execute  le code écrit ligne par ligne tout en respectant l'ordre établi dans le programme
